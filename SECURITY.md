# Security Policy

## Reporting a vulnerability in netscanner

If you find a security issue in netscanner itself (for example, a crafted service banner that causes script injection in the HTML report), please **do not open a public issue**. Report it privately using the "Report a vulnerability" button on this repository's Security tab.

Please include steps to reproduce and the affected version. We aim to acknowledge reports within 7 days.

## Responsible use

netscanner is intended for scanning systems you own or are explicitly authorized to test. Do not use it against third-party systems without permission.
